# Codex Companion v0.1.7

## 手机布局修复

- 长会话标题不再撑宽聊天区，正文与输入框完整适配手机屏幕。
- 长链接、代码、表格和图片限制在内容区内，发送按钮保持可见。
- 修正新版浏览器滚动返回值引发的 React effect 错误。
- 新增 320、390、720、1280 像素的 Chromium 回归测试及 Web CI。

## 剩余用量

- 手机打开左上角会话列表，可在底部查看电脑端 Codex 账户的剩余百分比与重置时间。
- 支持短周期、周额度及多个额度类别，在线且页面可见时每分钟刷新，也可手动刷新。
- 使用 Codex app-server 的只读账户额度接口；缺失、超时、离线和等待重置刷新都有明确状态。
- 响应仅返回原始请求网页，不广播，不传送账户凭据，也不开放消费或重置额度操作。

## 升级

先更新 Relay 与 Web，再安装新版 Windows Bridge 并启动。已有配对保留。额度功能需电脑端 Codex CLI 支持 `account/rateLimits/read` 且登录可提供额度的 ChatGPT 账户；不可用时可继续使用聊天。

下载附件包括 Windows 安装器、便携 ZIP 与 SHA-256 校验文件。服务器镜像提供 `v0.1.7` 与 `latest` 标签。
